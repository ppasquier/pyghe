# Citing

pyghe drives the simulation kernel of GHE Analysis from Python; it is not separate software. If it
helped your work, please cite the application:

> Pasquier, P. (2025). *GHE Analysis – Interactive simulation of ground-source heat pump systems*. P³
> Geothermal inc. <https://doi.org/10.5281/zenodo.15660526>

This is Zenodo's concept DOI. It resolves to the latest version, so the citation stays the same
from one release to the next.

When one method is central to your study, cite its paper as well: the spectral simulation, the
g-function, the borehole resistance, inclined boreholes or standing column wells.
[Methods](methods.md) says which paper each computation uses. Many of them are the work of my
students, and for them a citation is what counts.

To let others reproduce a result, publish the case file with it and the version of Analysis Suite
that computed it ([Reproducibility](reproducibility.md)).
